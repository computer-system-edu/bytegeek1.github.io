MODULE 01 // OVERVIEW

What is a Computer System?

A computer system is a complete setup that combines hardware and software to receive, process, store, and produce information. These elements work together to perform different computing tasks.

01 — Input

Data or instructions are entered into the system through input devices such as keyboards, mice, and scanners.

02 — Processing

The processor interprets instructions and performs the calculations needed to handle the input data.

03 — Output

Processed information is presented to the user through output devices such as monitors and speakers.

04 — Storage

Data and files can be stored for future access using storage devices such as SSDs and HDDs.

Hardware vs Software

CORE CONCEPT

Hardware

The physical components of a computer system that can be physically touched.

  • CPU
  • RAM
  • Motherboard
  • SSD / HDD
  • Keyboard
  • Mouse
  • Monitor
  • Power Supply

Software

Programs and instructions that tell computer hardware what tasks to perform.

  • Operating Systems
  • Web Browsers
  • Text Editors
  • Programming Tools
  • Games
  • Media Applications
  • Office Applications
  • Utility Programs
